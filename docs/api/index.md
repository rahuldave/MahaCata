These pages come from the docstrings and the types of the code. Each build writes them again.

- **provcat**: catalog URIs, the configuration, the resolver, `Catalog` with its reads, writes and snapshots, the hooks at its spots, the stores and the cache.
- **provrun**: the run context, the evidence, the broker, the resolver and the stager. Also the specs, the backends, the tools, the outputter, the runner and `provr`.

The sidebar lists one page for each public module.
